# Examples

Each example is a complete script. Make it executable and run it, or pass it
to `swift sh`:

```bash
swift sh Examples/terminal-rainbow
```

- [terminal-rainbow](terminal-rainbow): prints the 256-color terminal palette
  using only Foundation.
- [markdown](markdown): parses a Markdown document with Swift Markdown, pinned
  to an exact version, and prints its markup tree.
- [async-main-count-lines](async-main-count-lines): an `AsyncParsableCommand`
  built with Swift Argument Parser that counts the lines of a file.
