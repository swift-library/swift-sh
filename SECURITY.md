# Security

Report vulnerabilities privately using
[GitHub private vulnerability reporting](https://github.com/swift-library/swift-sh/security/advisories/new).
Include the affected version, environment and reproduction steps. Avoid posting
an exploitable vulnerability in a public issue.

The latest release line is maintained by default. Backports are decided per issue.
Scripts and their dependencies execute with the current user's permissions.
Review script source and dependency declarations before running them.
